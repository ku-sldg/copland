title: New Copland Software Release
---
We are pleased to announce the release of new Copland software tools and 
libraries that enhance the capabilities of our attestation framework. This 
release includes improved performance optimizations, expanded protocol support, 
and enhanced integration capabilities for distributed attestation scenarios.

Key features of this release:
- Enhanced Copland interpreter with improved execution efficiency
- Extended library support for common attestation patterns
- Improved documentation and examples for developers
- Better integration with existing attestation infrastructure

The new software is available on our [GitHub repository](https://github.com/ku-sldg) 
and includes comprehensive documentation to help users get started with the 
latest Copland tools.
